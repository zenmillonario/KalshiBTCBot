joint price/EMA9 turn or a confirmed corrective transfer retains its existing route. Cheapness and a

stale context does not manufacture a new parent veto. EMA9 remains primary; an EMA9/EMA30
crossing is not required for every genuine Release. [3]

Looking Glass now follows the active pattern
The brighter line gives you one clearly named continuation to inspect. It follows the current
engine-reported physical pattern, so a supported fresh upward leg can take precedence over a local
Heist label. The display remains separate from trading authority. [4]
Current pattern
What the bright line represents
Up or down rail
A comparable observed directional continuation.
Alternating mountain
A comparable next arc, including a witnessed historical turn.
Rolling mountain
A comparable arc in the current local direction, while the parent remains visible.
Fresh leg / sprout
Continuation of the current supported leg. A cross alone is not labeled a
confirmed Release.
Confirmed Release
Continuation in the confirmed handoff direction. A forming handoff keeps a
forming label.
Heist
A comparable observed rotation when that is the supported active pattern.
How to read the lines
Bright: the active pattern illustration. Fainter: alternative conditional paths. Pale fixed trace: the
earlier as-issued sample, held at its original coordinates so the realized candles can be compared
against it.
Paths come from already observed historical shapes. When a shorter historical segment is used, the
line stops at that segment's observed duration or the current contract close. It is not stretched
across the rest of the contract. Mirrored examples are labeled. If suitable history or a current source
is unavailable, the display says so. [4]
Research comparison has a defined boundary
The fixed samples survive a browser refresh while the same engine process runs. They are bounded
to 16 samples and clear on engine restart. This update does not create a durable forecast archive.
It also does not display calibrated win probabilities or turn line brightness into confidence. [4]
The actual chart drawing code was checked with an offline canvas renderer. That verifies drawing and guards; it is not a
native Windows browser-layout test. The complete default TV layout and position panels are retained. [4]
